# 3D Models

Printable models and enclosures. Each design lives in its own folder with print-ready STLs, STEP files for editing in Onshape/Fusion, and source where it's parametric.

| Model | Description |
|---|---|
| [xiao-esp32s3-case](xiao-esp32s3-case/) | Slim case for the Seeed XIAO ESP32S3 with the flex antenna in its own bay, flexure buttons, LED light pipes. Standard and pin-breakout versions. |
